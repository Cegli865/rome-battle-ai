Other projects built on the same idea: a language model commanding the computer's army in a strategy game.

## ugcw-battle-ai - Ultimate General: Civil War

<https://github.com/mmtt-bit/ugcw-battle-ai>

The same idea for *Ultimate General: Civil War*. A C# plugin compiled into the game's assembly sends the
battlefield to a Python planner server, and an LLM (Claude by default) commands the AI army. It follows the design
of this project - a planner server, strategy and rules files, battle reports - but targets another game and
engine, so it is a separate project rather than a fork.
